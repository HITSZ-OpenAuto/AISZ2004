# 2026 年 AISZ-23 信息论复习资料

本目录收录信息论课程的复习总览、讲解型材料、疑问解答、知识清单和章节测试。

## 内容说明

- [信息论复习总览](信息论复习.html)：知识图谱、考试重点与复习进度管理
- `模块一_基础工具.html`、`模块二_信源编码.html`、`模块三_信道编码.html`：按主题组织的讲解型材料
- `信息论疑问解答.html`：重点概念、计算与证明问题的补充说明
- [知识清单](知识清单/README.md)：Lecture 2–16 的分讲知识清单
- [章节测试](章节测试/README.md)：Lecture 2–16 的交互式自测

## 使用方式

1. 下载本目录并保持现有文件结构不变。
2. 用浏览器打开 `信息论复习.html`，再从总览进入三个讲解模块。
3. 按需打开 `知识清单/` 和 `章节测试/` 中对应 Lecture 的 HTML 文件，进行复习和自测。
4. 页面无需安装依赖；公式使用 MathJax 渲染，首次加载时需要联网。
